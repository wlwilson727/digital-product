# Service Price Lab: frequently asked questions

**How do I start?** Extract the complete ZIP, keep the files together and open `index.html` in a current desktop or mobile browser. No installation or account is needed. The example loads fictional data; replace it with your own assumptions.

**Where is my data stored?** This application attempts to save inputs in browser local storage. File-based storage behavior varies by browser. Export JSON after each working session and keep a secure backup. Nothing is transmitted by this application.

**Can I move between devices?** Export editable JSON, copy that file securely, then import it in the same product on the other device. Import validates the product identifier and supported version.

**How do I share the result?** Export the report CSV for spreadsheet analysis, or use Print / save PDF. A CSV is a report, not an import format. Only the product's exported JSON can be imported.

**Does currency selection convert amounts?** No. It changes display formatting only. Enter every amount in the same currency. Supported formats: USD, EUR, GBP, CAD, AUD.

**Can I use it commercially?** Yes, within your own business under the included license. Reports may be sent to clients; source files may not be resold or distributed.

**What happens with invalid inputs?** Calculation errors appear above the form. Correct them before exporting a report. No guaranteed business outcome follows from any estimate.

**Will it sync or connect to my bank?** No. This is an offline planning tool with manual inputs. Future version upgrades and external integrations are not promised.

**What accessibility features are included?** Labeled inputs, keyboard-focus indicators, responsive layouts and plain text result labels. Test your preferred assistive technology; formal accessibility certification has not been performed.
