# Owner launch review checklist

Status: local preparation, **not launched**. No live store integration exists.

- [ ] Review release archive, instructions, screenshots, calculations and license for each product.
- [ ] Perform manual browser checks, keyboard navigation and real-device mobile review; reconcile any automated coverage claims with actual test reports.
- [ ] Verify current official Shopify plan, payment processing, delivery app costs, taxes, refunds, digital-goods consumer disclosures and policy requirements for intended jurisdictions.
- [ ] Approve the first product, proposed price, preview assets, copy and existing-store branding fit.
- [ ] Provide least-privilege Shopify access only when upload/integration work is approved; do not paste credentials into chat.
- [ ] Choose a supported fulfillment app and explicitly approve installation/configuration; no installation currently authorized.
- [ ] Upload reviewed draft product, disable physical shipping where appropriate, attach correct ZIP and verify variants/bundles.
- [ ] Test a complete checkout with allowed test-payment mode: confirmation, file access, resend, limits, mobile download, license and refund handling.
- [ ] Verify analytics/session denominators, consent, email preferences and synthetic/actual separation.
- [ ] Approve publication separately from preparation; product must not be published automatically.
- [ ] Approve any experiment's exact spend cap, audience, claims and dates; stop at cap.
- [ ] Record actual orders/refunds/support and reconcile payouts before scaling.

Recommended first pilot: Service Price Lab. Next actions are owner review of the completed package, approved Shopify draft/test-order integration, then a small explicitly approved demand experiment. Alternatives remain available if the owner prefers a private pilot.
